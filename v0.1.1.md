## 本次更新

- **忽略 zip 备份包**：`.zip` 不再被识别为图书。若你以 zip 作为原始图书的备份，扫描、上传和下载入库时都会忽略它们，避免与解压后的书籍重复。真正的漫画包请使用 `.cbz` 或 `.cbr` 格式。
- **图书清单导出**：新增导出全部图书清单为 CSV 的能力，包含标题、作者、系列、标签、元数据质量、文件路径与文件类型等字段，便于在其他工具中进一步整理与分析。

## What's new

- **Ignore zip backups**: `.zip` files are no longer recognized as books. If you keep zip archives as backups of your source books, they are now skipped during library scan, upload, and download import, avoiding duplicates alongside the extracted books. Use `.cbz` or `.cbr` for genuine comic archives.
- **Library export**: export the full book list to CSV, including title, author, series, tags, metadata quality, file path, and file type, for further organization and analysis in other tools.
