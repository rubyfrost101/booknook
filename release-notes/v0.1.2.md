## 本次更新

- **图书查重与相似图书归档**：新增四层模糊查重，识别同一本书的多份文件——相同标题与作者的重复 PDF、同书 PDF 与 EPUB 并存、不同版本（第 2 版 / 修订版 / 8th Edition）以及不同翻译。可在「整理 → 重复作品」面板中按置信度审阅并合并，合并不删除源文件。
- **图书自动分类打标签**：根据目录结构与文件名自动添加分类标签，覆盖 DK 百科、外刊精读、小学生教材（Wonders / Journeys）、中学教材（数理化 / Glencoe）、历史、计算机等常见书库组织。
- **识别准确性提升**：修复音频副本序号（如 `(1)`）被误判为卷号、`第2版` 等版本号误判、超长作者串残留等问题。
- **导入性能优化**：消除识别与导入热路径上每次调用重复的集合构造与系统调用，大批量导入更快。
- **导出按钮修复**：设置 → 系统日志页的「导出图书清单」按钮在嵌入模式（应用中心）下不再隐藏。
- **新品牌形象**：换上「书架与台灯」暖色 Logo 与图标。

## What's new

- **Duplicate detection & archiving**: a four-tier fuzzy matcher now finds the same book across duplicate PDFs, co-existing PDF and EPUB copies, different editions (2nd ed., revised, 8th Edition), and different translations. Review and merge them by confidence in Organize → Duplicate works; merging never deletes source files.
- **Automatic categorization**: books are tagged from their directory structure and filenames, covering DK encyclopedias, intensive-reading journals, elementary textbooks (Wonders / Journeys), middle-school subjects, history, and computer science collections.
- **Sharper recognition**: fixed audio copy numbers such as `(1)` being mistaken for volume numbers, edition markers like `第2版` being dropped or misparsed, and overlong author strings.
- **Faster imports**: removed per-call set rebuilding and redundant syscalls on the recognition and import hot paths.
- **Export button fix**: the "Export book list" action in Settings → System logs is visible again in embedded mode.
- **New branding**: a warm bookshelf-and-lamp logo and icons.
