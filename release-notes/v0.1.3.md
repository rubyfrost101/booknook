## 本次更新

- **联网补全图书信息（一键批量整理）**：新增「立即整理候选」按钮与 `POST /organize/runs` 接口，可手动把书库中信息不完整的图书批量加入整理队列，逐本按数据源限流调用豆瓣 / Bangumi / AI 插件识别，补全系列、系列序号、出版状态等缺失元数据。默认策略不再需要等待定时任务，识别设置面板一键即可发起。
- **接口契约收口**：`/organize/runs` 支持 `workIds` 定向整理与 `limit` 限流参数（1–2000，越界自动收敛）；补齐路由覆盖断言与端点级回归测试。

## What's new

- **One-click metadata enrichment**: a new "Organize candidates now" button and `POST /organize/runs` endpoint let you queue every book with incomplete metadata for recognition in one shot. Books are matched one by one against Douban / Bangumi / AI providers at their rate limits, filling in missing series, volume numbers, and publication status without waiting for the schedule.
- **Tighter API contract**: the runs endpoint accepts `workIds` scoping and a clamped `limit` (1–2000); route-coverage assertions and endpoint regression tests were updated accordingly.
